# Phase 5D synthesis summary

## Scope and constraints

Phase 5D is synthesis-only. No new statistical analyses were run. This summary integrates completed outputs from:

- Phase 2/4 coupling inference artifacts
- Phase 5 BAC integration artifacts
- Phase 5B environmental driver artifacts
- Phase 5C plant-diversity hypothesis artifacts

All Phase 5D outputs were generated by `scripts/analysis/phase5d_synthesis.py` using existing result tables only.

## Input sources and column mapping

### Coupling synthesis (`final_coupling_rankings.csv`)

Primary source: `results/phase5_bac_integration/phase5_bac_coupling_summary.csv`

Mapped columns:

- `pair` → `pair`
- `branch` → `branch`
- `mantel_spearman_mean` → `Mantel`
- `mantel_perm_pvalue_conservative` → `Mantel p`
- `mantel_ci_lower_conservative`, `mantel_ci_upper_conservative` → `Mantel CI if available`
- `procrustes_similarity_mean` → `Procrustes similarity`
- `procrustes_ci_lower_conservative`, `procrustes_ci_upper_conservative` → `Procrustes CI if available`
- derived flags: `BAC-inclusive flag`, `AMF-centered flag`
- derived metric: `coupling_strength = (Mantel + Procrustes similarity)/2`

### Environmental synthesis (`final_environment_driver_summary.csv`)

Primary sources:

- `results/phase5b_environmental_drivers/phase5b_dbRDA_summary.csv`
- `results/phase5b_environmental_drivers/phase5b_predictor_ranking.csv`

Mapped columns:

- `adjusted_r2` (best of primary vs geography_sensitivity) → `dbRDA adjusted R²`
- model selection (`model_type`) → `best environmental model`
- top `predictor` by max `delta_adj_r2` in selected model → `top predictor`
- `delta_adj_r2` for `predictor == pH_KCl` in selected model → `pH contribution`
- `adjusted_r2(geography_sensitivity) - adjusted_r2(primary)` → `geography sensitivity delta`

### Plant-diversity synthesis (`final_plant_diversity_summary.csv`)

Primary source: `results/phase5c_plant_diversity/phase5c_model_comparison.csv`

Mapped columns (from `record_type=model_summary`, `model_scope=primary`):

- best non-base hypothesis (max `delta_adjusted_r2_vs_base`) → `best plant hypothesis`
- max `delta_adjusted_r2_vs_base` → `delta adjusted R² vs abiotic base`
- hypothesis-specific effects:
  - B (`abiotic_plus_alpha`) → `alpha effect`
  - D (`abiotic_plus_pool`) → `pool effect`
  - C (`abiotic_plus_dark`) → `dark effect`
  - E (`abiotic_plus_compl`) → `compl effect`

### Integrated pair synthesis (`final_pair_synthesis.csv`)

Inner join on `pair, branch` across:

- `final_coupling_rankings.csv` (`coupling_strength`)
- `final_environment_driver_summary.csv` (`dbRDA adjusted R²`)
- `final_plant_diversity_summary.csv` (`delta adjusted R² vs abiotic base`)

Mapped output fields:

- `coupling strength`
- `environmental explained variation`
- `plant-diversity added variation`
- rule-based `interpretation label`

## Major synthesis results

### Coupling structure

Top coupling combinations by `coupling_strength`:

1. `BAC↔ITS` (presence/absence): 0.574
2. `EUK↔ITS` (presence/absence): 0.538
3. `EUK↔ITS` (CLR): 0.535

This indicates strongest integrated coupling among BAC↔ITS and EUK↔ITS combinations under the current synthesis metric.

### Environmental structure (Phase 5B carry-through)

- Best-fit environmental models were consistently `geography_sensitivity` for top rows.
- `pH_KCl` was the top predictor across reported top combinations.
- `dbRDA adjusted R²` reached ~0.278 (highest in `BAC↔ITS` CLR).
- Geography sensitivity increased fit modestly (positive deltas in top rows).

### Plant-diversity contribution (Phase 5C carry-through)

- Best hypothesis for all top rows: **B (`abiotic_plus_alpha`)**.
- Largest observed plant-added variation in this synthesis: ~0.019 (`AMF↔ITS` presence/absence).
- Relative single-predictor pattern remained:
  - `alpha` strongest positive contributor
  - `pool` secondary positive contributor
  - `dark` weaker positive contributor
  - `compl` negative in top rows

### Integrated interpretation

`final_pair_synthesis.csv` labels show:

- EUK↔ITS presence/absence classified as **strongly coupled/environment structured + plant associated**.
- BAC↔ITS presence/absence classified as **strongly coupled/environment structured**.
- AMF-linked pairs were typically **weakly coupled but plant associated**, reflecting lower coupling score but positive plant-added variation.

## BAC and AMF-specific notes

- **BAC-inclusive (BAC↔ITS)**: highest coupling score overall in presence/absence and highest environmental explained variation in CLR.
- **AMF-centered (AMF↔ITS, AMF↔EUK)**: lower coupling scores than BAC↔ITS/EUK↔ITS, but consistently positive plant-diversity added variation, supporting AMF-linked plant association signals.

## Caveats

- Phase 5D introduces no new inferential testing; it reuses previously computed outputs.
- `coupling_strength` is a synthesis metric (mean of Mantel and Procrustes similarity), not a standalone inferential statistic.
- Interpretation labels are rule-based thresholds for communication and may be adjusted in manuscript drafting.
- Environmental summary chooses best model between primary and geography-sensitivity by adjusted R²; this is a descriptive selection, not new model fitting.
