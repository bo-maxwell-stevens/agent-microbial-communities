# Phase 1 Interpretation Cautions

## Core caution
EUK–ITS is **not fully independent** biologically/taxonomically because fungi are part of Eukaryota.

## Implication for signal interpretation
A strong EUK–ITS coupling signal may validate that the reduced-space pipeline captures coherent eukaryotic/fungal structure, but it should **not** be overinterpreted as novel independent cross-kingdom coupling.

## Reporting guidance
- Treat EUK–ITS as a **sensitivity / positive-control** result.
- Avoid using EUK–ITS as the main headline result for independence claims.
- Emphasize pairings with greater taxonomic independence in the main narrative:
  - AMF–BAC
  - BAC–ITS
  - BAC–EUK_nonfungal (if partitioning is feasible)
  - AMF–EUK_nonfungal (if feasible)
  - AMF–ITS (with caveats)

## If EUK cannot be cleanly partitioned
If fungal vs nonfungal EUK separation is not possible or uncertain in a given analysis slice, report EUK–ITS only as a conservative sensitivity/positive-control observation and avoid mechanistic interpretation.

## Additional non-causal guardrails
- Do not claim microbial interaction networks from these reduced-space couplings.
- Do not infer assembly mechanisms definitively.
- Distinguish exploratory reproducibility from statistically convincing independent ecological inference.
