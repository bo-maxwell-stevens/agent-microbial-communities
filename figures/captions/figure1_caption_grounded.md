# Figure 1. Grounded study overview and analysis workflow

Figure 1 summarizes the DarkDivNet microbial coupling workflow using only verified repository outputs. The canonical inventory contains 143 samples, of which 99 have environmental metadata and geographic coordinates available in the current repository. Microbial domain availability counts are BAC = 140, ITS = 139, EUK = 135, and AMF = 120. Intersection across all four microbial domains is 112 samples, and the final analytical cohort used for confirmatory coupling and downstream phases is 84 samples (all four domains plus metadata).

The workflow panels should show: (i) study-system map points derived from real sample coordinates (where available), (ii) dataset construction from canonical inventory to final cohort, (iii) Phase 2 confirmatory coupling and Phase 5A/5B integration branches, and (iv) Phase 5C plant-diversity hypothesis testing (A-G). Environmental-driver and plant-diversity hypothesis layers should be described as explanatory analyses on the same verified cohort and pair/branch combinations.

Country totals and biome-class counts are not asserted here because explicit country/biome fields were not found in the inspected repository metadata tables.
